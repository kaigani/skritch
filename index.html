A FEW SMALL DETAILS

Good to know.

Is this connected to Skitch?+

No. Skritch is an independent project inspired by the ease of Skitch. It adds its own approach to image layers, canvas cropping and quick video work. It is not affiliated with Skitch or Evernote.

Can I keep editing after I save?+

Save a .skritch project to retain the editable document. Skritch’s PNG export can also retain editable document data when it fits within the metadata limit. Other image formats export a flattened image.

What about Windows?+

Windows x64 downloads are available above: a setup EXE, an MSI installer, and a portable ZIP. The portable version needs WebView2 already installed. Keep its video tools and licenses next to skritch.exe. These builds are unsigned; see the Windows installation guide for details.

Screen Recording is already enabled. Why am I asked again?+

Older development builds used a different signing identity. Quit Skritch, install this build in Applications, then remove the old Screen Recording entry and add the installed app again. Future builds use the same Developer ID. See the README for the full migration steps.

Found a bug or have an idea?+

This is an early public release. Open an issue on GitHub with your OS version and a few steps to reproduce it. Please remove private information from any screenshots you share.
